# Dataset Information

This project uses public GEO RNA-Seq / microarray datasets.

## Training Dataset

GSE99039

Used for:
- Differential Expression Analysis
- Feature Selection
- Biomarker Discovery
- Machine Learning Training


## External Validation Dataset

GSE165082

Used for:
- Independent validation
- Cross-platform evaluation


Raw datasets are not included in this repository because of their large size.
